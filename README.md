# 싱가포르 재보험 브로커 시뮬레이션

작은 재보험 중개회사(가상)의 책임자가 되어 58주 동안 일하는 경영 시뮬레이션이에요. 축구 감독 게임처럼 메일을 읽고, 상대를 알아 가고, 선택을 쌓아 가요. 혼자 하는 게임이고, 인터넷 연결 없이 브라우저에서 돌아가요.

> 재보험을 잘 몰라도 괜찮아요. 모르는 말에는 점선 밑줄이 있고, 눌러 보면 쉬운 말로 풀어 줘요. 읽은 말은 **용어 도감**에 모여요.

## 열기

- **바로 하기**: <https://hongjinhyotop-cpu.github.io/reinsurance-broker-sim/>
- **내 컴퓨터에서**: 폴더에서 `python3 -m http.server 8000`을 실행하고 <http://localhost:8000> 을 열어요. 파일을 더블클릭해서 열면(`file://`) 데이터를 못 읽어서 안 돼요.

진행 상황은 이 브라우저에 자동 저장돼요. 설정 화면에서 파일로 내보낼 수도 있어요.

## 한 판 하는 법

1. **새 게임**을 누르고 난이도를 골라요(아래 참고).
2. **인박스**의 메일을 읽고 답해요. 답에는 *행동 점수*가 들어요. 점수는 매주 6점이 새로 채워지고 남겨 둬도 이월되지 않아요.
3. **고객·재보험사 DB**에서 상대와 미팅해요. 미팅할수록 `???`이던 성격이 흐릿한 범위로, 나중에는 확정으로 보여요.
4. **플레이스먼트**에서 계약 하나(막대 100%)를 재보험사들이 나눠 갖게 짜요. 지분과 가격을 제안하고, 100%가 차면 고객에게 제출해요. 인셉션(보장 시작일) 전에 확정하는 게 중요해요.
5. 오른쪽 위 **Continue**로 한 주를 넘겨요. 사건이 터지거나 마감이 다가오면 멈춰요.
6. 58주가 끝나면 이사회가 **S~D 성적표**를 줘요. 이사회 신뢰가 너무 낮아지면 중간에 해고돼요.

막히면 화면 위의 **다음으로 할 일** 띠를 보세요(끌 수 있어요). 정답은 알려 주지 않고 어디를 볼지만 가리켜요.

## 보통과 쉬움

| | 보통 | 쉬움 |
|---|---|---|
| 계약을 못 채웠을 때의 벌칙 | 큼 | 절반 |
| 해고되는 이사회 신뢰 | 20 미만 | 10 미만 |
| 미팅 한 번으로 알게 되는 정도 | 기본 | 1.5배 |
| 재보험사가 거절해도 참아 주는 횟수 | 3번 | 5번 |
| 안내 문구 | 짧게 | 구체적으로 |

규칙과 점수 계산은 같아서, 같은 성적이면 같은 등급이에요(성적표에 난이도가 적혀요). 난이도는 시작할 때 한 번만 고르고 도중에는 바꿀 수 없어요.

## 알아 두면 좋은 것

- 시드 칸에 같은 숫자나 단어를 넣으면 같은 사건 흐름으로 다시 해 볼 수 있어요.
- 키보드만으로도 할 수 있어요. 첫 Tab에서 "본문으로 건너뛰기"가 나와요.
- 화면은 종이와 잉크 느낌이에요. 결과는 도장으로 찍히고, 보낸 쪽은 인장으로 구분돼요. 주가 넘어갈 때 달력 장이 넘어가고 숫자가 올라가는 작은 움직임이 있는데, 컴퓨터 설정에서 "움직임 줄이기"를 켜 두면 모두 꺼져요.
- 모든 회사와 사람 이름은 가상이에요.

## 만드는 사람을 위한 메모

빌드 도구 없는 순수 HTML/CSS/JS예요. 설계는 [`docs/design.md`](docs/design.md)가 기준이고, 작업 규칙은 [`CLAUDE.md`](CLAUDE.md)에 있어요. 서버를 연 뒤 `/tests/`를 열면 자동 테스트가 돌아요. 밸런스 확인은 `node tests/balance/sim.mjs 300 normal,easy`로 해요(설계 §9.6).
